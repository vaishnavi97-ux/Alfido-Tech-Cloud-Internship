# Alfido-Tech-Cloud-Internship
Cloud Computing Internship Tasks submissions for Alfido Tech.
This repository contains the tasks completed during my Cloud Computing Internship at Alfido Tech.

## Tasks Completed

### Task 1: Deploy a Static Website on AWS S3
- Hosted a static website using AWS S3.
- Configured public access and website hosting.

### Task 2: Host a Web Server on AWS EC2
- Launched and configured an EC2 instance.
- Deployed a web server and accessed it through a public IP address.

### Task 3: Create a Serverless Function using AWS Lambda
- Developed a Python-based AWS Lambda function.
- Generated JSON output through a public Function URL.

### Task 4: Deploy a Docker Container on Cloud VM
- Installed Docker on AWS EC2.
- Deployed an Nginx container and exposed it to the internet.
